2. 직접 움직여보기 — 슬라이더로 코드가 계산하는 걸 그대로 재현

아래 도형에서 쥐(분홍 점)를 마우스로 끌어보고, 슬라이더로 각도·거리를 바꿔보세요. 오른쪽 숫자는 코드의 각 변수(to_trap, dist, inward...)가 실시간으로 계산되는 값 그대로입니다.

쥐(분홍 점)를 드래그해서 옮겨보세요. 점선 원 = 협공 발동 반경(trigger_radius_m).
