# 조종자 도주 규칙 카드 (Operator Protocol)

이 문서는 미니카(RC)를 조종하는 사람이 시행 중 지켜야 할 규칙입니다.
**포획 구역의 위치는 알려주지 않습니다.** 각 시행마다 4개 후보 중 하나가 무작위로 선택되며,
콘솔에는 출력되지 않고 로그 파일에만 기록됩니다 (`test/field_logger.py`).

## 3원칙

1. **평상시**: 벽면을 따라 일정한 속도로 이동합니다. 공간 중앙으로 나가지 않습니다.
2. **로봇이 약 40cm 안으로 들어오면**: 즉시 반대 방향으로 급가속해 도망칩니다.
   체감 기준: **로봇 한 대 크기(가로 34cm)만큼 가까워지면** 도망친다고 보면 됩니다.
   (이 값은 `config/herding_params.yaml`의 `flee_reaction_distance_m`(0.42)와
   반드시 같아야 합니다. 2026-08-08에 매뉴얼이 1.0m로 낡아 있던 걸 시뮬레이션
   값에 맞춰 정정했습니다. 0.7m로 올리는 안도 검토했지만 -- OAK-D Pro의 RC카
   감지 범위(~1.5m) 안이고 방 전체 봉인이 가능해진다는 장점이 있었으나 --
   실측 결과 현재 몰이 알고리즘에서는 성공률이 85.8%에서 80.8%로 오히려
   떨어져서 채택하지 않았습니다. 표적이 더 멀리서부터 도망치면 Driver가
   밀어붙일 자리를 잡기 전에 빠져나가기 때문입니다.)
3. **3~5초 이동마다 1~2초 정지**합니다.
4. **막다른 구석으로는 들어가지 않습니다.** 도망칠 때 앞이 막힌 쪽보다
   **트인 쪽을 고릅니다.** 로봇이 다가와도 구석에 갇히는 방향이면, 필요하면
   **로봇 옆을 스쳐서라도 트인 쪽으로 빠져나갑니다.**
   (2026-08-09 추가. 실제 쥐의 행동이고, 동시에 **로봇 두 대가 필요해지는
   조건**이다. 이 규칙이 없으면 -- 즉 로봇 반대 방향으로만 밀리면 -- 로봇
   한 대로도 90% 이상 잡히므로 두 번째 로봇이 아무 기여를 하지 못한다.
   실측: 이 규칙을 지키는 표적은 로봇 한 대로 39.3%, 두 대로 84.0%.)

## 대조군 실험 조건 (각 10회)

| 조건 | 로봇 동작 | 목적 |
|---|---|---|
| CONTROL-A | 로봇 정지 | 우연 성공률 baseline |
| CONTROL-B | 로봇 무작위 순찰 | 단순 움직임 효과 분리 |
| TREATMENT | 몰이 알고리즘 ON | 실제 성능 |

## 기록

모든 시행은 `test/field_logger.py`의 `FieldLogger`로 CSV에 기록됩니다.
규칙 위반(위 2번 원칙 위반: 로봇이 70cm 이내인데 표적이 로봇 쪽으로 이동)은
`detect_rule_violations()`로 사후 자동 판정됩니다. 위반률이 20%를 넘는 시행은 분석에서 제외하고
리포트에 명시합니다.
