# System Monitor 개선 기록

이 문서는 현재 코드에 남아 있는 관제 UI 개선 결과만 요약한다. 과거에 실험했던 인증·로컬 저장·기록 조회 기능은 현재 범위에서 제거되었으며 개발 기준은 `SYSTEM_MONITOR_SCOPE.md`다.

## 현재 반영된 개선

- 발표 화면에서 읽기 쉽도록 핵심 글자 크기와 대비 조정
- 의미가 중복되던 상단 요약 카드 제거
- 정상 상태는 간결하게, Offline·경고 상황은 배너로 강조
- 로봇 선택 탭의 긴 역할명 축약과 상세 카드 중복 문구 제거
- 지도 범례 접기, 마커 라벨 충돌 완화, 선택 로봇 강조
- 로봇 방향·최근 이동 경로·현재 대상 연결선 표시
- 탐지 마커 클릭 시 현재 세션의 좌표·로봇·수신 시각 표시
- 로봇별 색과 탐지 대상별 색의 의미 분리
- 카메라 카드의 중복 메타데이터 축소
- 모니터링 책임을 벗어나는 로봇 제어 버튼·명령 API·ROS 발행 코드 제거
- Mock/ROS 공통 Runtime 계약과 실제 지원 capability 기반 버튼 제어
- 제거한 화면과 관련된 미사용 CSS·JavaScript·템플릿 정리

## 현재 구조의 원칙

- 관제 화면은 상태 확인과 예외 대응에 집중한다.
- 현재 서버 실행 중 받은 데이터만 보여준다.
- 영구 이력과 로봇 DB는 System Monitor가 임의로 구현하지 않는다.
- 실제 ROS 값이 없는 항목은 가짜 정상값이나 진행률로 채우지 않는다.
- `map` frame임이 확인되지 않은 좌표는 지도 위에 억지로 표시하지 않는다.

## 검증

```bash
python3 -m unittest discover -s tests -v
```

브라우저 시연은 Mock으로 확인하고, 실제 통합은 토픽 타입·frame·발행 주기를 먼저 확인한다.
